## ⚙️ Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/umairzahid16005-ui/portfolio.git
```

### 2. Open the Project

```bash
cd portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Vite will start the development server and display the local URL in the terminal.

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

The production files will be generated inside the `dist` directory.
